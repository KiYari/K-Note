# Startup guide


##For Windows:
1. Install wsl:
	open PowerShell as administrator and type: wsl --install
	
2. Install docker
	go to https://docs.docker.com/desktop/install/windows-install/ and install docker
	
3. Use startup.sh or startup-dedicated.sh for dedicated startup.


##For Linux:
1. Install docker:
	follow installation guide: https://docs.docker.com/desktop/install/linux-install/
	
2. Use startup.sh or startup-dedicated.sh for dedicated startup.
